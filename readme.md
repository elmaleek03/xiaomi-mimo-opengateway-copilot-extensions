<h1 align="center">Xiaomi MiMo for Copilot Chat — OpenGateway Edition</h1>

**This is a modified version of [sdmapvstool.xiaomimimo-for-copilot](https://marketplace.visualstudio.com/items?itemName=sdmapvstool.xiaomimimo-for-copilot)**, pre-configured to use the [OpenGateway](https://opengateway.gitlawb.com) proxy for free access to **Xiaomi MiMo V2.5 Pro** — no API key required.

## What's different?

The default base URL is set to `https://opengateway.gitlawb.com/v1/xiaomi-mimo`, so you can use MiMo V2.5 Pro out of the box without signing up or providing an API key.

> **⚠️ Free access is available until May 29, 2026.**

## Install

**Linux / macOS:**
```bash
curl -sL https://raw.githubusercontent.com/elmaleek03/xiaomi-mimo-opengateway-copilot-extensions/refs/heads/master/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/elmaleek03/xiaomi-mimo-opengateway-copilot-extensions/refs/heads/master/install.ps1 | iex
```
